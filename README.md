# AllTimer

Habits, time-based workouts & wellness timers in a single-page web app.

- **Today** — dashboard with stats and quick actions
- **Habits** — streaks, sub-tasks, reminders & 52-week heatmap
- **Workouts** — time-based modes: Interval, EMOM, Tabata, AMRAP
- **Timers** — Pomodoro, Meditation, Wim Hof
- **Calendar** — month view of everything logged

## Live

https://d-j-cosmos.github.io/alltimer/ — or open `index.html` locally.

## Privacy

All data stays in your browser (`localStorage`), nothing is sent to any server.
Use **Export / Import** (JSON) in Settings to sync between devices.

## Stack

Single HTML file, vanilla JavaScript, no dependencies.
